# Buddies Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the animal avatars with Buddies (12 bodies × 12 colors, cursor eyes, feet, accessories, state motion) everywhere avatars show today.

**Architecture:** A buddy is stored as a plain string: the body alone (`"gumdrop"`, signature color) or `"body/color"` (`"gumdrop/jade"`). Strings keep the existing Map/Set/localStorage plumbing (room uniqueness, per-chat looks) unchanged; only the value set and names change. Old animal names parse into buddies through one legacy table.

**Tech Stack:** React 19, TypeScript, Vitest + Testing Library, plain CSS (`--zli-*` tokens).

**Spec:** `docs/superpowers/specs/2026-11-13-buddies-design.md` (look source of truth: `docs/superpowers/specs/2026-11-13-buddies-mockup.html`).

## Global Constraints

- Bodies, in order: gumdrop, capsule, plus, cloud, mushroom, peanut, jelly, wedge, squircle, bulb, house, bean.
- Colors: paper `#ece8df`, clay `#c9825b`, tomato `#ef5a47`, tangerine `#ff8a3d`, butter `#f2cf5b`, lime `#a6d44f`, jade `#2fbf8f`, sky `#4aa8ff`, indigo `#6f6cf6`, orchid `#c56ff0`, rose `#ff7aa8`, slate `#8a93a3`.
- Legacy: fox→gumdrop, owl→squircle, otter→jelly, cat→cloud, panda→bean, penguin→mushroom, bear→peanut, rabbit→plus, frog→capsule, chick→wedge; unknown→gumdrop.
- Ready (idle) motion only at size ≥ 40; other moods animate at any size; `animateTeammates` off or reduced motion stops all motion.
- Cheeks and shine only at size ≥ 30.
- UI copy: no em dashes, no emoji (antislop R-02, R-04).

## Review Focus

- Saved settings with an old `animal` field: the teammate keeps a matching buddy, not a reset to gumdrop. (Task 1 test.)
- `zli.chat.animals` localStorage holding old animal names: chats keep a mapped buddy. (Task 1 test.)
- A `"body/color"` string with an unknown color or body: falls back to the body's signature or gumdrop, never crashes rendering. (Task 1 test.)
- Notification icon render (static markup, no CSS) still produces an SVG with inline fills. (Task 2 test.)
- Picker keyboard use: every body and color is a button with `aria-pressed` and a label. (Task 4 test.)
